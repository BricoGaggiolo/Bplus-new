# B+ Gestionale — nuova versione

Nuova implementazione stabile del gestionale HR B+ per La Quattro S.r.l.

## Funzioni
- Dashboard per negozio
- Dipendenti
- Turni settimanali e auto-generazione
- Storico settimane
- Assenze e ferie
- Corsi con sessioni
- Punti vendita
- Report CSV
- Notifiche interne
- Interfaccia responsive PC/mobile
- Login autorizzato B+ (utente iniziale)

La specifica originale di riferimento è `bplus-specifiche.md`.
